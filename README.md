# Lazy Office (local prototype)

A tiny local HTML/CSS/JS prototype for an isometric "Lazy Office" dashboard.

## Run

Just open `index.html` in a browser.

## What it does
- Isometric room (simple SVG placeholder)
- Clickable agents with status dots
- Right panel shows selected agent
- Activity log simulates updates

## Customize
Edit `app.js` → `AGENTS` (names/roles/status/positions) and `STATUS_STYLES`.
Replace the SVG background in `index.html` with your own art when ready.
